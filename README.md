# AI Concepts

A beginner-friendly collection of Markdown notes covering the fundamental concepts of Artificial Intelligence. This repository is designed as a learning resource for students and developers who want to understand the core technologies behind modern AI.

## Topics Covered

- Artificial Intelligence (AI)
- Machine Learning (ML)
- Natural Language Processing (NLP)
- Large Language Models (LLMs)
- Retrieval-Augmented Generation (RAG)

## How to Use

1. Clone the repository.

```bash
git clone https://github.com/Nasteha153/git-and-github-capstone
```

2. Open the project folder.

```bash
cd ai-concepts-notes
```

3. Navigate to the folder directory and open any Markdown file using:
   - Visual Studio Code
   - GitHub
   - Any Markdown viewer
